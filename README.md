# 🌈 MoodMix — AI-Driven Mood-Based Media Player 
### **Videos • Music • Exercises — Recommended by Your Facial Expressions**

🔗 **Live Demo:** https://moodmix-player.netlify.app/

MoodMix is an interactive AI-powered multimedia platform that detects your facial expressions in real time and recommends personalized **music**, **videos**, and **exercise routines** according to your mood.

This project is built using the **PERN Stack (PostgreSQL, Express.js, React.js, Node.js)** and integrates real-time **facial emotion recognition** to enhance user experience.

---

## ✨ Features

### 🎭 Real-Time Mood Detection  
- Detects facial emotions such as **happy**, **sad**, **neutral**, **angry**, **surprised**, etc.  
- Works directly in the browser — **no webcam images are uploaded or stored**.

### 🎵 Mood-Based Music Recommendations  
- Smart playlists that match your detected mood.  
- Smooth music player interface.

### 🎬 Mood-Based Video Suggestions  
- Videos curated to uplift, relax, or match your emotional state.

### 🏋️ Mood-Based Exercise Sessions  
- Exercise routines based on mood: relaxing, energetic, stress relief, etc.

### 🔐 Secure Authentication  
- JWT authentication with password encryption.  
- User account creation, login, and protected API routes.

### 📱 Fully Responsive & Modern UI  
- Clean layout that works perfectly on mobile and desktop devices.

## 🎯 How It Works

1. Open MoodMix in your browser.  
2. Allow webcam access.  
3. Facial expression detection runs **locally** on your device.  
4. Choose one of the 3 categories:  
   - Music  
   - Videos  
   - Exercises  
5. You receive curated recommendations for your current mood.

---

## 🔐 Privacy & Safety

- No webcam images are ever stored or sent to a server.  
- Emotion detection runs **100% locally** in the browser.  
- All passwords are hashed using industry-standard encryption.  
- JWT authentication ensures secure data access.
